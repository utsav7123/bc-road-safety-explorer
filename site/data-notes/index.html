Data notes

Know what each number can and cannot say.

The dashboard uses public aggregate RoadSafetyBC tables. This page keeps source coverage, refresh cadence, and interpretation limits visible so the analysis is not separated from its caveats.

Fatalities by road user type

Used to compare categories such as drivers, passengers, pedestrians, cyclists, and motorcyclists where those categories are present in the published table.

Fatalities and serious injuries by region

Used for broad police traffic region comparisons. These values are aggregate regional outcomes, not precise crash locations.

Speeding involvement

Used as a descriptive contributing-factor series. It should not be interpreted as a complete causal explanation for road fatalities.

Historical comparability

Police attendance and reporting practices have changed over time. Long-run comparisons should therefore be interpreted with care.

Refresh

The project downloads the public source files during the deployment workflow, so a new deployment can pick up revised source tables without committing raw data to the repository.

This project is an independent portfolio project. It is not an ICBC product, official forecast, or official RoadSafetyBC dashboard.
