About

A portfolio project built around transparent public-data analysis.

I built BC Road Safety Explorer to practice the kind of work that sits between data engineering, analytics, reporting, and decision support: defining metrics, checking source limitations, finding trends, building explainable baselines, and presenting results clearly.

What I worked on

Python and Pandas data preparation, KPI definitions, time-series summaries, regional comparisons, a baseline forecast, automated testing, GitHub Actions, and an interactive web presentation layer.

What I avoided

The project does not invent individual crash records or claim that aggregate regional data provides exact crash hotspots. It also does not present its baseline projection as an official forecast.
